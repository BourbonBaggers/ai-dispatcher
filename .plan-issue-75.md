# Issue #75: Progressively Climb the Model Ladder Across Recovery Retries

## Goal
Make automatic recovery improve model capability across repeated failures instead of retrying the same assigned model for the full repair budget and then jumping directly to the frontier.

## Current Behavior
- When a repair attempt fails, the system either:
  1. Retries with the same model (up to maxAttempts)
  2. Escalates once to the frontier model
  3. Holds for human intervention

- Recovery state tracks: `attempts` and `escalated` (boolean)
- No intermediate models are used between assigned and frontier

## Desired Behavior
- First retry the assigned model once at the appropriate effort
- If that retry fails, climb to the next compatible model/tier
- Continue climbing through a configured ladder (e.g., Haiku → Sonnet → Opus)
- Progress effort as appropriate within a model before or alongside tier escalation
- Stop only after the frontier attempt fails, preserving existing durable exhaustion contract
