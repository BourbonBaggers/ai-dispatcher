# Issue #109: Resume completed green PRs after interrupted runs

## Goal
An interrupted run whose branch already carries a finished, published PR must resume
autoship for that PR instead of relaunching agents until the model ladder is "exhausted".
Interruptions are infrastructure events: they must never be counted as model failures,
and an `autoship-held` exhaustion must be backed by real, failed model attempts on work
that is still unresolved.

## Facts established (code at c47c79e, production read-only)
- internal-tools #773 run (PR #787): eight launches, each one `claude exited with code 0`
  -> `UNPUBLISHED WORK: clean exit left dirty files after earlier commits` -> `CI PASSED`
  -> `interrupted` ("The launcher found unpublished work..."). Exhaustion reason: "The
  process remained interrupted after 3 frontier resume attempts."
- The only dirty entry in that checkout is `?? .dispatcher-deps-key`: the dependency-cache
  marker written by `scripts/deps-cache.mjs` (#101). The target-policy reconciler only
  excludes `.dispatcher` and `.dispatcher-prompt.md`, so the marker made every clean exit
  "dirty" and every agent (correctly) refused to commit it.
- The checkout HEAD equals the published branch head (7ac04590), and the plan
  `docs/plans/2026-10-01-issue773-cheap-local-verify.md` marks all four milestones `[DONE]`.
- In this repository the same marker was committed by the capture safety net for #102
  (e1e23f6), so it is tracked here; any key change would read as a dirty tail.
- `runScanOnce`'s resume cap path sets `recovery.agent.attempts = ciSelfHealMaxAttempts`
  without any model failing, escalates to frontier, and after three more interruptions
  calls `exhaustRun` — a model-exhaustion hold built entirely from interruptions.
- Resumes never consult GitHub: a run with an open, green PR is relaunched regardless.
- `gh pr list --head <branch> --state all --json number,state,isDraft,headRefOid,url`
  works on gh 2.63.2; an unknown branch returns `[]` with exit 0.
- Production state has no live holds to migrate (every historical hold has shipped).
